# 📰 Fake News Detection using Machine Learning & Streamlit

A machine learning project that identifies whether a news article is **real** or **fake** using **Natural Language Processing (NLP)** techniques and **Scikit-learn**, with a user-friendly web app built in **Streamlit**.

---

## 📌 What You’ll Learn
- Data preprocessing and cleaning for text data.
- Feature extraction using **TF-IDF Vectorizer**.
- Building and training machine learning models using **Scikit-learn**.
- Evaluating model performance with accuracy and other metrics.
- Deploying the fake news detection model using **Streamlit**.

---

## 📊 Topics Covered
- Text preprocessing: lowercasing, punctuation removal, stopword removal, stemming.
- Feature engineering with TF-IDF vectorization.
- Classification using:
  - Logistic Regression
  - Naive Bayes
  - (Optional) SVM or Random Forest
- Real-time prediction UI built using Streamlit.

---

## 🚀 Tools and Libraries Used
- **Python 3.x**
- **Pandas**, **NumPy**
- **Scikit-learn**
- **String**, **re**
- **Streamlit**

---

## 🛠️ How to Run the Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com/BinduSundarapu/fake-news-detection.git
cd fake-news-detection
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app:**
   ```bash
   [Fake News Detection Streamlit App](https://erhwajgzepg3dcj6w2uxdn.streamlit.app/)
   ```
